# Indian Equity Sector Rotation Research

A Python-based quantitative research project that analyzes the performance of major Indian stock market sectors using historical market data. The project automates data collection, sector analysis, stock ranking, report generation, and blog creation to study sector rotation across the Indian equity market.

---

## Project Overview

Sector rotation is one of the most important concepts in investment research. Instead of focusing only on individual companies, this project studies how capital moves between sectors over time.

The pipeline automatically downloads historical market data, calculates monthly sector returns, ranks stocks within each sector, generates charts, creates structured reports, and produces publishable Markdown blogs.

Current Version: Phase 1 (Automated Research Pipeline)
